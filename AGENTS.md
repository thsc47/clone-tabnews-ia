# clone-tabnews-ia

Clone do TabNews (curso.dev) construído com auxílio de IA.

## Stack

- Next.js com App Router
- React
- JavaScript puro (sem TypeScript)
- Módulos ES
- npm como gerenciador de pacotes

## Comandos

```bash
npm install     # instalar dependências
npm run dev     # servidor de desenvolvimento
npm run build   # build de produção
npm start       # servir o build de produção
```

Consulte o `package.json` para a lista atual de scripts.

## Convenções

- Idioma da interface: pt-BR.
- Commits com mensagens curtas, em minúsculas e em inglês.
- Trabalho direto na branch `main`.
- Preferir configurar a plataforma (painel da Vercel) a adicionar código ou arquivos específicos de vendor ao projeto.
